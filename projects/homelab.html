Infrastructure project

Virtualization & Homelab

A small personal lab for gaining practical experience with virtualization, managed switching, and safe experimentation with network services.

← Back to projects

Project goals

I want a controlled environment where I can deploy systems, test configurations, troubleshoot issues, and document what I learn.

Current setup

  • Proxmox VE host running on a laptop.
  • Managed gigabit Ethernet switch.
  • Compact rack and patch-panel equipment.
  • Lab network planned to remain isolated from everyday home devices where practical.

Planned learning

  • Deploy Linux and Windows virtual machines.
  • Experiment with VLANs and separated lab networks.
  • Practice DNS, DHCP, firewall rules, logging, and monitoring.
  • Document backups, updates, access controls, and recovery procedures.

Skills practiced

Proxmox VE Virtualization Managed switching Segmentation System administration

Security considerations

I will avoid exposing management interfaces directly to the public internet. Remote access should use deliberate access controls, strong authentication, current updates, and restrictive firewall rules.
