Personal Portfolio Website

A responsive static website designed to introduce me and give employers a clear way to explore individual project write-ups.

← Back to projects

Design goals

I wanted the homepage to feel like a personal introduction rather than a résumé pasted into a webpage. It includes education, hobbies, career interests, skills, and short project summaries.

Site structure

  • index.html — homepage and project summaries.
  • styles.css — shared styling and responsive layout.
  • projects/ — individual pages with project details.
  • images/ — image assets for the website.

Technology and deployment

The website uses HTML and CSS with a small JavaScript snippet for the current year. It can be hosted as a static site through Azure Static Web Apps.
